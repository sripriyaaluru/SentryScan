How this works

  1. Add a Target (must resolve inside AUTHORIZED_TARGETS to ever be scanned).
  2. Run Recon (Nmap) to discover hosts/ports/services.
  3. Run Vulnerability Assessment to match services against the CVE dataset.
  4. Optionally run Authentication Testing with your own lab-only credential lists.
  5. Compute Risk and generate a Report (HTML/PDF).

All actions are also available via the REST API under /api (see /docs).
